깃허브에 현재 프로젝트를 안전하게 백업/배포하는 4단계 워크플로우를 실행한다.

## 실행 순서

### 1단계 — 깃 저장소 확인 및 초기화
- `git status`를 실행한다.
- 오류가 나거나 "not a git repository" 메시지가 나오면 `git init`을 먼저 실행한다.
- `.gitignore`에 `.env`가 포함되어 있는지 확인한다. 없으면 추가한다.

### 2단계 — 리모트 연결 확인
- `git remote -v`로 origin이 설정되어 있는지 확인한다.
- origin이 없으면 사용자에게 깃허브 리포지토리 URL을 물어보고, `git remote add origin <URL>`을 실행한다.

### 3단계 — 변경 사항 스테이징 및 커밋
- `git status`로 변경된 파일 목록을 확인한다.
- `.env`, `node_modules/`, `.expo/` 등 민감하거나 불필요한 파일이 스테이징되지 않도록 주의한다.
- `git add` 로 관련 파일을 스테이징한다 (`.env`는 절대 포함 금지).
- 커밋 메시지는 한국어로 작성하고, 이번 작업 내용을 간결하게 요약한다.

### 4단계 — 푸시
- `git push -u origin main`을 실행한다.
- main 브랜치가 없으면 `git branch -M main` 후 재시도한다.
- 성공하면 사용자에게 완료 메시지와 함께 리포지토리 URL을 알려준다.
